# Sitr never-block list
# Same format as sources/<category>/domains.txt: one name per line, `#` comments.
#
# The compiler FAILS if any entry in any category or optional list would
# block one of these names: an entry E blocks a name N when N == E or N ends
# with "." + E (every platform matches a listed entry and all its
# subdomains). The import tool drops such upstream entries and counts them.
#
# This is a backstop against over-broad entries, not a statement that these
# sites are endorsed. It protects each name and nothing more: listing
# google.com stops an entry for google.com (or for com), but it does not stop
# a separate entry for a hostname under it. Hosts that must keep working on
# their own (the SafeSearch targets) are listed individually for that reason.
#
# Shared hosting suffixes that are in the Public Suffix List (github.io,
# blogspot.com, vercel.app, ...) are already refused by the public-suffix
# guard and are not repeated here, except where a name belongs here on its
# own merits (cloudfront.net, githubusercontent.com, nhs.uk happen to be in
# both).
#
# Exempt by design: the per-site media lists and the opt-in lists that
# declare "neverBlockExempt" in ../optional/lists.json. Even there, only an
# entry that is a strict subdomain of a never-block name is allowed; an apex
# such as google.com still fails. See tools/compiler/src/guards.ts.
